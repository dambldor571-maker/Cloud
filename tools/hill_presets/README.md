# Hill presets (2 x N hexes)

Real hills from the Emmental (Switzerland) elevation data, smoothed, max 3.2 m, soft wide
transitions, rendered grassy (no rock). Same file format and composer as
`tools/mountain_presets`; generator: `tools/terrain/terrain_gen.py hills`.

Counts: 2x2: 6, 2x3: 5, 2x4: 4, 2x5: 3, 2x6: 2 (x2 with mirroring).
