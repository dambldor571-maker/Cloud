# Майстерня юнітів (Windows)

Окрема програма на Godot 4.3 (Forward+): налаштування 3D-моделі юніта і рендер
спрайтів для гри. Прев'ю показує модель тією ж сценою, з якої рендеряться кадри
(камера 65°, сонце NE 75°, шейдер зношеності `tools/models/weathered.gdshader`),
на траві й сітці тестової карти, як у грі.

Збірка: Actions → «Unit Workshop (Windows)» → Run workflow; архів
`UnitWorkshop.zip` з'являється в релізі `unit-workshop`.

## Робота

1. **Відкрити модель…** — glb, gltf, fbx або obj.
2. Розмір, поворот (гармата праворуч), зсув корпусу, фарба, зношеність, бруд.
3. **Частини**: роль кожної групи деталей, колір, тінь.
   **Текстури**: для всієї моделі або окремої частини — колір, нормалі (сила,
   формат DirectX), запечені тіні (AO, сила), шорсткість, металевість, масштаб;
   шахова сітка для перевірки розгортки.
   **Світло і тіні**: тіні дрібних деталей (сила, радіус, різкість, на сонці),
   сонце, м'якість його тіні, тінь на землі, підсвітка, розсіяне світло,
   експозиція, контраст, насиченість.
4. **Перевірка**: 18 напрямків, окремий поворот башти, «Постріл».
5. **Зберегти налаштування…** → `<назва>.unit.json`.
6. **Рендер спрайтів…** → вибрати папку. Туди йдуть:
   - `<назва>_hull_<i>.png`, `<назва>_turret_<i>.png`, `<назва>_turret_<i>_r<k>.png`
     (для моделі без башти `<назва>_<i>.png`),
   - `<назва>.json` — опис спрайтів у форматі гри (`assets/units/`),
   - `<назва>_sheet.png` — усі напрямки на траві, як у грі,
   - `<назва>.unit.json` — налаштування.

## Командний рядок

```
UnitWorkshop.exe -- --model=D:/models/t72.glb --config=D:/models/t72.unit.json --out=D:/sprites
```

Моделі в програму не вбудовані: файли лишаються на вашому ПК.
