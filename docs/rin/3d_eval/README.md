# Оцінка 3D-моделей Рін з Tripo (22.10.2026)

Вхід: 4 ортографічні ракурси (ChatGPT, боді, тугий пучок, A-поза), Tripo Multi-view, HD Model.
Скрипти оцінки запускаються в Blender 4.2 headless: `blender -b -P <script>.py -- <model.glb> <out_dir>`.

| Версія | Налаштування | Результат |
|---|---|---|
| v1 | один меш, текстура 2K, Ultra Mesh, 100k | 91 413 трикутників, 1 меш; після злиття дублів по швах — 45 765 вершин, 186 неманіфолдних ребер, 5 уламків; текстура — атлас ~1000 клаптиків; очі лише на текстурі; волосся злите з головою; рига немає |
| v2 | Generate in Parts, без текстури, Quad 50k | 49 358 трикутників (Quad не спрацював), **24 частини**: волосся окремо, обличчя окремо, очі окремі, тулуб/шия/руки/ноги/кисті/ступні окремо + дрібні уламки пальців |
| v3 | Parts + текстура + риг VRM 1.0 Humanoid | 48 068 трикутників, **42 частини, 42 текстури**; скелет **55 кісток** за іменуванням VRM (J_Bip_*): хребет 4, шия, голова, очі (J_Adj_*_FaceEye), повні пальці, пальці ніг; усі частини заскінені; тестова поза: плечі, лікті, шия, стегно, коліно працюють, волосся йде за головою; **розриви між окремими частинами** на плечах, шиї і стегнах при деформації |

Пропорції (v1, масштаб до 170 см): стегна 39,1 см, плечі ≈43 см (з розведеними руками), талія ≈18 см ширини, глибина грудей 31 см; голова з пучком 29 см (без пучка ≈24–25 → ≈7 голів).

Висновок: тіло з Tripo — придатна заготовка; потрібно: злити частини тіла в один меш (волосся й очі лишити окремо), ретопологія в квади, перенесення ваг VRM-скелета, одна текстура/розгортка, нова голова з повіками й ротом для міміки.

## v4 — зібране тіло (22.10.2026, скрипти `body_build.py` → `body_final.py` → `body_check_fix.py`)

Вхід: v3 (риг VRM, 42 частини). Кроки: кожну частину тіла закрити (`fill_holes`) → злити → voxel remesh (0,3 см) → головна оболонка → **Quadriflow** (працює лише після масштабування ×100: на дрібному масштабі Blender хибно вважає меш неманіфолдним) → перенесення ваг з оригінальних частин (`DATA_TRANSFER`, POLYINTERP_NEAREST, ліміт 4 кістки, згладжування) → перевірка шипів відносно воксельної поверхні (63 вершини >0,5 см притягнуто) → риг → тест пози → GLB.

Результат `docs/rin/3d/rin_body_v1.glb`: **Body** — 23 550 квадів (47 100 трикутників), 0 неманіфолдних ребер, UV (smart project), матеріал — плоский колір шкіри; **Hair** — 7 529 трикутників (злиті пасма, ~25 матеріалів з оригіналу); **Eyes** — 186; **Misc** — дрібна деталь; скелет VRM 55 кісток. Тестова поза — без розривів на плечах, ліктях, шиї, стегнах, колінах; пальці гнуться.
Залишилось у цьому етапі: одна запечена текстура замість ~25 у волоссі; обличчя без рис (голова будується окремо); дрібні ворсинки біля шиї від оригінальних пасом.
