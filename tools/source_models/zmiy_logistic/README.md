# НРК «Змій Логістичний» (Rovertech, 2026) — 3D-модель

Hero-asset без LOD, зібраний процедурно скриптами Blender з нуля. Габарити взято з 3D-моделі
пожежної версії «Змія» на ArtStation (кадри облету й рендери, надані власником проєкту); корма —
як у попередній (логістичній) версії моделі. Трубчастих надбудов (дуга каркаса, поручні, щогла камери)
немає — за вимогою. Матеріали поки прості, однотонні (див. «Матеріали»).
Перевірено на **Blender 4.5.14 LTS** і **Blender 5.2** (модуль `bpy` 5.2.2).

![3/4 спереду](renders/zmiy_front34.jpg)

| Файл | Що це |
|---|---|
| `zmiy_logistic.blend` | сцена: модель, модулі (сховані), колізії; текстури — відносні шляхи `textures/` |
| `zmiy_logistic.fbx` | модель + колізії `UCX_*` (Unreal); текстури лежать поряд у `textures/` |
| `zmiy_logistic.glb` | модель для Godot / веб (наліпки вбудовані) |
| `zmiy_logistic_modules.glb` | опційні модулі в тих самих координатах: Starlink Mini, вантаж |
| `textures/` | наліпки логотипу (у режимі `full` — ще й PBR-карти) |
| `renders/` | рендери: 3/4 спереду, збоку, спереду, згори, ззаду, знизу, з модулями |
| `zmiy_build.py` | геометрія й ієрархія (усі розміри — словник `P` на початку) |
| `zmiy_texture.py` | UV-розгортка; у режимі `full` — запікання масок і текстури зі зносом |
| `zmiy_export.py` | експорт `.blend/.fbx/.glb` і рендери |
| `make_decals.py` | генерує текстури наліпок (Pillow) |

## Як перезібрати

```
blender -b --factory-startup --python zmiy_build.py --python zmiy_texture.py --python zmiy_export.py
```

- Тільки геометрія з простими матеріалами: відкрити `zmiy_build.py` у Blender → Scripting → Run Script.
- `ZMIY_TEX_MODE=full` — увімкнути запікання й процедурні текстури зі зносом (за замовчуванням `simple`:
  лише UV і однотонні матеріали). Роздільність — `TEX_RES` у `zmiy_texture.py` (`ZMIY_TEX_SCALE=0.5` для перевірки).
- `ZMIY_MASK_CACHE=_cache` (режим `full`) зберігає запечені маски; після правок геометрії кеш треба видалити.
- `ZMIY_SAMPLES`, `ZMIY_RES_PCT` — якість/розмір рендерів, `ZMIY_NO_RENDER=1` — без рендерів.
- Лише рендери з готового файлу: `ZMIY_NO_EXPORT=1 ZMIY_VIEWS=front34,side blender -b zmiy_logistic.blend --python zmiy_export.py`.
- Прогін на 4 ядрах CPU без GPU: збірка й експорт ~1 хв, рендери ~20 хв (Cycles, 160 семплів);
  режим `full` додає ~35 хв запікання.

## Ієрархія, осі, масштаб

```
Zmiy_Logistic            empty на землі під центром кузова, (0, 0, 0)
├─ Body                  корпус, кузов-«ванна», ніс, корма, фаркоп, кріплення
│  ├─ Decal_Logo_Nose    наліпки — окремі площини (товарний знак Rovertech,
│  ├─ Decal_Logo_Rear     можна сховати або замінити, матеріали Zmiy_Decal_*)
│  └─ Decal_Text_Rear
├─ Wheel_FL / FR / RL / RR   півот у центрі колеса, обертання навколо локальної X
├─ Module_Starlink / Module_Cargo   сховані опційні модулі
└─ UCX_Zmiy_Logistic_00…06   прості опуклі колізії (колекція Zmiy_Collision)
```

- Blender: **X праворуч, Y вперед (ніс), Z вгору**, 1 юніт = 1 м, земля на Z = 0.
- glTF: ніс дивиться в −Z (це «вперед» у Godot). FBX: експорт з `-Z forward, Y up`.
- Ліві колеса — дзеркальний меш правих (той самий UV); 2 меші (`Zmiy_Wheel_R`, `Zmiy_Wheel_L`) на 4 об'єкти.

## Розміри (м)

**Як виміряно.** Масштаб дає шина: на боковині читається маркування KABAT **10.0/75-15.3**
(зовнішній Ø 0,77 м). По кадрах облету (вид збоку, спереду, ззаду) розв'язано спільну задачу
«камера орбіти + габарити» за ~35 точками (маточини, кути бортових стінок, кути лобового листа,
кути кормового борту, силуети шин). Поздовжні розміри й висоти — з майже ортографічного
бічного рендера. Потім контур готової моделі накладено на кадри референсу з тих самих камер:
колеса, стінки, ніс і корма збігаються з точністю ~1–2 см.

| Параметр | Попередня версія | Зараз (з референсу) |
|---|---|---|
| Ширина по бортових стінках | 1,56 | **1,23** |
| Ширина по шинах (колія по зовнішніх краях) | 1,52 | **1,41** (центри коліс X ±0,557) |
| Ширина нижнього корпусу між колесами | 0,91 | **0,73** |
| Довжина кузова (борт → «підборіддя» носа) | 1,63 | **1,86** (1,90 з вушками на носі, 1,99 з кулею фаркопа) |
| Колісна база | 0,75 | **0,873** |
| Колесо Ø / ширина шини | 0,65 / 0,245 | **0,77 / 0,287** (KABAT 10.0/75-15.3, обід 15,3″) |
| Палуба / верх бортових стінок | 0,745 / 0,83 | **0,862 / 0,99** |
| Кормовий борт: ширина / низ / верх | 1,01 / 0,60 / 0,90 | **0,80 / 0,70 / 1,03** |
| Висота без надбудов | 1,38 (з дугою) | **1,03** (верх кормового борту) |
| Кліренс під корпусом / під носом | 0,23 / 0,25 | **0,29 / 0,29** |
| Лобовий лист (лого): ширина верх / макс. / низ | 1,28 / — / 1,12 | **0,93 / 1,00 / 0,75** |

Тепер шини виступають за бортові стінки на ~8 см з кожного боку, як на референсі; кузов
вужчий за колію і довший — пропорції ширина : довжина ≈ 0,66 замість 0,96.
Для порівняння: у пресі для платформи «Змій» наводять 2,15 × 1,5 м і колеса 75 см (ймовірно, з навісним
обладнанням) — колеса й ширина з цим узгоджуються.

## Конструкція

- **Нижній корпус** — вузький короб між колесами (0,73 м) з вертикальними ребрами жорсткості
  на бортах, бобишками моторів-коліс і захисним листом днища на болтах.
- **Кузов-«ванна»**: палуба 4 мм, бортові стінки 5 мм (висота 0,14 м) зі скосами на кінцях,
  ряд справжніх прорізів (восьмикутники 88×44, овали 74×26, Ø11) і похилі прорізи на скосах,
  косинки під палубою, болти внизу стінок.
- **Ніс**: похилий верхній лист-трапеція між стінками → лобовий лист із логотипом
  (злам, розширення, зрізані нижні кути) → нижній лист назад до днища; вибірки під передні колеса,
  овальні буксирувальні отвори, П-ручка, вушка по боках «підборіддя», стрижень-фіксатор і гак.
- **Корма — як у попередній версії** (на референсі пожежної версії корма інша, з високим бортом
  із прорізами — її не взято): широкий відкидний борт зі скошеними верхніми кутами на рівні кінців
  бортових стінок, ребро й завіса знизу, дві засувки-шпінгалети зі скобами на кормових кутах,
  помаранчева кнопка, напис і логотип; під бортом поличка і нижня панель на задній стінці корпусу
  зі скошеними нижніми кутами, двома клямками, кулею фаркопа на вигнутому хвостовику і проушинами.
- **Колеса**: шина KABAT IMP 10.0/75-15.3 — блоковий протектор (24 кроки, 4 ряди шашок у шаховому
  порядку, плечові блоки заходять на боковину, через один довгий/короткий), глибокий суцільний диск
  15,3″ зі штампованим кільцем, 5 гайок (PCD 135), ковпачок маточини, вентиль.
- Пожежне обладнання референсу (насос, трубопроводи, щогла з камерою, рукави) не моделювалось.
- Геометрія: ~130 тис. трикутників (Body 32,5 тис., колесо 24,2 тис. × 4); листовий метал з товщиною
  й фасками, болти й гайки — геометрія, справжні прорізи в стінках.

## Що прибрано і чому

| Що | Рішення |
|---|---|
| Дуга каркаса з діагоналями, бічні поручні | прибрано повністю (вимога власника) |
| Блок камери на дузі | прибрано разом із дугою |
| Модуль вил (трубчастий концепт) | прибрано |

## Місця, які ТЗ позначало «не підтверджено»

| Питання | Рішення |
|---|---|
| **Третя вісь** | немає, 4×4 — на всіх кадрах облету по два колеса на борт |
| **Задня частина** | як у попередній версії моделі (за фото логістичної версії виробника) ([рендер ззаду](renders/zmiy_rear34.jpg)) |
| **Днище** | рівне дно корпусу з захисним листом на болтах, бобишки моторів-коліс ([рендер знизу](renders/zmiy_bottom.jpg)) — реконструкція, днища на референсі не видно |
| **Логотип** | окремі наліпки `Decal_*` з альфою, стилізований трафарет; товарний знак — для комерційної гри потрібен дозвіл |

## Матеріали

Зараз — **прості однотонні PBR-матеріали** (metal/rough), без текстурних карт і зносу:

| Матеріал | Колір (sRGB) | Roughness | Metallic | Де |
|---|---|---|---|---|
| `Zmiy_Paint_Olive` | #434A37 | 0,74 | 0 | корпус, кузов, ніс, корма |
| `Zmiy_Rubber` | #1C1C1C | 0,90 | 0 | шини |
| `Zmiy_Rim_Black` | #151515 | 0,50 | 0 | диски, маточини |
| `Zmiy_Bolt_Zinc` | #8A8A85 | 0,35 | 1 | болти, гайки, засувки, клямки |
| `Zmiy_Steel_Bare` | #5E5E5A | 0,38 | 1 | фаркоп |
| `Zmiy_Knob_Orange` | #C8561E | 0,45 | 0 | кнопка борту |
| `Zmiy_Decal_Logo/Text` | текстура з альфою | 0,82 | 0 | наліпки |

UV-розгортка вже зроблена (корпус і колеса окремо, ліві колеса — дзеркальний меш правих з тим самим UV),
тож текстури можна додати пізніше. Готовий процедурний варіант: `ZMIY_TEX_MODE=full` — запікання масок
у Cycles і PBR-набори `Zmiy_Body` (4096) / `Zmiy_Wheel` (2048) зі сколами, пилом і брудом
(BaseColor, Normal OpenGL, ORM і окремі AO/Roughness/Metallic).

## Unit Workshop (рендер спрайтів для гри)

- Відкрити `zmiy_logistic.glb`; частини згрупуються як `Body` і `Wheel` (ролі вгадуються за назвою).
- З простими матеріалами зручно брати фарбу шейдера гри («наша фарба», зношення шейдера — як для інших
  юнітів); колір команди в модель не вшито.
- Ніс у GLB дивиться в −Z; у Unit Workshop «вперед» — +X, тож потрібен поворот `yaw` на 90°.
- Довжина для масштабу (`length_m`): 1,99 м з кулею фаркопа (найдовша горизонтальна сторона).

## Відомі обмеження

- Референс — модель пожежної версії; логістична версія може відрізнятися деталями (кріплення на
  палубі, корма). Габарити платформи в лінійці «Змій» спільні.
- Точна форма похилого верхнього листа носа під насосом на референсі не видна — реконструйовано.
- Логотип — стилізоване наближення трафарету, не оригінальний файл виробника.
