# Юніти Glory of Generals 3 → Hexfront

Беремо лише ролі й ідеї. Моделі, назви, числа й графіку робимо свої (Unit Workshop).
Категорії GoG3 взято з APK (`unit_infantry`, `unit_panzer`, `unit_artillery`, `unit_airforce`, `unit_navy`,
`exarmy` — 10 елітних підрозділів × 3 ступені), склад категорій — із публічних описів гри.
Реалізацію відкладено (§35, §38).

| GoG3 | Hexfront (клас канону) | Статус |
|---|---|---|
| Піхота | Піхота | є в каноні |
| Інженери | Інженерні юніти | відкладено (§33) |
| Бронеавтомобіль | Бронемашина | є |
| Легкий танк | Бронемашина / БМП | є |
| Середній, важкий танк | Танк | є |
| Винищувач танків, штурмова САУ | Танк (протиброньова роль) | не окремий клас |
| Польова артилерія | Ствольна артилерія / САУ | є |
| Реактивна артилерія | РСЗВ | є |
| Зенітна гармата | ППО + радар | є |
| Транспорт піхоти | БТР / вантажівка | є |
| Винищувач, бомбардувальник, штурмовик | Літак (§14) | є |
| — | Ударний вертоліт | є (у GoG3 немає) |
| Есмінець, крейсер, лінкор, підводний човен, авіаносець | Флот | відкладено |
| Фортифікації (бункер) | Окопування; споруди — з інженерами | §38 |
| Елітні підрозділи (3 ступені) | «Гвардійський» юніт після 3 зірок ветеранства | §38 |

Нових класів не додається: усе, що є в GoG3 і потрібне сучасній війні, канон уже покриває.
Відкритими лишаються інженери та флот.
