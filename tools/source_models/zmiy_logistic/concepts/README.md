# Концепти обладнання (тест, не в основній моделі)

Скрипти будують поточну модель (`zmiy_build.py`) і додають поверх неї варіанти обладнання, потім
рендерять тестові зображення. Основну модель не змінюють.

| Файл | Що це |
|---|---|
| `sensors_abc.py`, `sensors_abc.jpg` | сенсорний блок, антени, Starlink: A — голова + Starlink на носі; B — без виступів; C — поворотна голова (Turret) + задній місток |
| `masts_m123.py`, `masts_m123.jpg` | надбудови: M1 — портал із профільної труби; M2 — відкидна телескопічна щогла; M3 — Т-пілон спереду |
| `superstructure.py` | **надбудова-портал** для Starlink, камер і антен (v20, футуристичний дизайн): A — «Крило», B — «Ореол», C — «Козирок»; сідла на бортиках на 3 болтах M10, ноги на шарнірі (портал складається). Без зображень — варіанти перемикаються у вікні 3D-перегляду |
| `deck_modules.py`, `deck_modules.jpg` | змінні модулі на палубу на спільній рамі-піддоні (8 болтів M10 крізь отвори Ø11 у бортиках): L1 — припаси; L2 — евакуація (двоє нош); B1 — дистанційний кулеметний модуль 12,7 мм (Turret); B2 — мінування (27 мін, відкидний жолоб); B3 — РЕБ / ретранслятор |

```
blender -b --factory-startup --python concepts/sensors_abc.py -- <папка_для_зображень>
blender -b --factory-startup --python concepts/masts_m123.py -- <папка_для_зображень>
blender -b --factory-startup --python concepts/deck_modules.py -- <папка_для_зображень>
blender -b zmiy_logistic.blend --python concepts/superstructure.py   # додає Top_A/B/C і пакує viewer/
```

Рішення власника ще не ухвалене: сенсори й щогли відкладено (робота повернулась до корпусу), модулі — на розгляді.
