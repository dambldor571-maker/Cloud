# Майстерня юнітів

Веб-сторінка для налаштування 3D-моделі юніта перед рендером спрайтів
(`tools/render_units.gd`). Опублікована як приватний artifact:
https://claude.ai/artifact/JFhN74e5pzV5Y1LLCJ5THW

- Модель відкривається з пристрою (glb/fbx/obj) і нікуди не завантажується.
- Прев'ю: клітинка 5,5 м, камера 65°, сонце NE 75°, кільце сторони як у грі.
- Збережені налаштування лежать у базі сторінки (колекція `units`), звідти їх
  забирає Claude для рендера в Godot.
