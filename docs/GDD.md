# Frontline: Modern War — дизайн-документ (чернетка)

Покрокова стратегія для Android, натхненна механіками European War 7, але в сучасному сеттингу
(ХХІ століття). Назва робоча. Усі матеріали (графіка, звук, тексти) мають бути власними —
копіювати ассети чи бренд оригіналу не можна, лише ідеї ігрового процесу.

## Ядро геймплею (що беремо з European War 7)

| Механіка EW7 | Сучасний аналог у нашій грі |
|---|---|
| Гексагональна карта, покрокові бої | Те саме, карти реальних регіонів + вигадані сценарії |
| Генерали з навичками | Командири (штаб, спецпризначення, логістика, РЕБ) |
| Королівства, дипломатія | Країни та коаліції, санкції, альянси |
| Технології | Дерево технологій: дрони, РЕБ, ППО, високоточна зброя |
| Міста дають дохід | Міста, заводи, НПЗ, порти — економіка й постачання |
| Кампанії, завоювання | Кампанії-сценарії + режим «Глобальний конфлікт» |

## Юніти (план)

- **Наземні:** піхота, спецпризначенці, БМП, танк, САУ, РСЗВ, ППО, інженери.
- **Повітряні:** розвідувальний дрон, ударний дрон, гелікоптер, винищувач, бомбардувальник.
- **Морські:** корвет, есмінець, підводний човен, десантний корабель.

Принцип «камінь–ножиці–папір»: танки сильні проти піхоти, але не бачать дронів;
ППО знищує дрони й авіацію, але слабка проти наземних; артилерія б'є здалеку, але беззахисна в ближньому бою.

## Дорожня карта (крок за кроком)

1. ✅ **Прототип**: гекс-карта, 5 типів юнітів, рух, зона контролю, бій з контратакою,
   захоплення міст, дохід, мобілізація, простий ІІ, перемога через захоплення столиці.
2. **Android-збірка**: експорт APK, іконка, автозбірка через GitHub Actions.
3. **Контент карт**: редактор/формат сценаріїв (JSON), перша реальна карта регіону.
4. **Командири**: досвід, рівні, навички.
5. **Технології та економіка**: дерево досліджень, типи ресурсів, постачання.
6. **Авіація й флот**: нові шари юнітів, порти, аеродроми.
7. **Кампанія**: серія сценаріїв зі сюжетом, збереження/завантаження.
8. **Графіка та звук**: спрайти, анімації, ефекти, музика.
9. **Поліровка й публікація**: баланс, навчання, Google Play.

## Технології

- Рушій: **Godot 4.3** (безкоштовний, відкритий, добре експортує на Android).
- Мова: GDScript.
- Рендер: GL Compatibility (найширша підтримка Android-пристроїв).
