# Налаштування юнітів — чекліст для нових моделей (чернетка на погодження)

Усе, що ми вже налаштували для Т-72. Для нової техніки проходимо цей список зверху вниз:
кроки 1–2 — підготовка моделі, 3 — рендер, 4 — гра. Колонка «Т-72» — поточні значення.

## 1. Вихідна модель (конвертер `tools/source_models/convert_<юніт>.py`)

| Налаштування | Що це | Т-72 |
|---|---|---|
| Формат | OBJ/FBX/GLB → конвертуємо в GLB | OBJ → `t72_rambo.glb` |
| Назви частин | `Hull`, `Turret`, `Gun`, `Wheel_*`, `Track_*`, `Sprocket_*`, `Idler_*` | так |
| Що прибрати | зайві деталі (бочки, колода, кулемет, написи…) | бочки й кріплення, колода й кріплення, кулемет НСВТ, плаский напис |
| Дірки в сітці | заткнути допоміжною геометрією | нижні борти за катками (`HullLower`) |
| Нормалі | згладжування до 35°, записуються у файл | так |
| Ліцензія | звідки модель і чи можна публікувати | Rambo (p3dm.ru) — **лише особисто** |

## 2. Фарба й деталі (для кожної частини, за префіксом назви)

| Налаштування | Що це | Т-72 |
|---|---|---|
| `color` | колір фарби частини | корпус/башта/гармата `(0.20, 0.205, 0.18)` — колір з вашого фото |
| `tyre` | радіус гумового бандажа катка, м | 0.29 |
| `links` | малювати траки на гусениці | так |
| `no_shadow` + `lift` | частина не приймає тіні сонця + легке підсвічування (ходова) | катки, ведучі/напрямні колеса, гусениці; 0.45 |
| `detail` + `detail_rect` | намальовані деталі з рельєфом (ящики, решітки, болти) | `t72_hull_detail.png` на корпусі |
| `mud_height` | до якої висоти бруд, м | 1.1 |
| Зношення | бруд, пил, потьоки, сколи (спільний шейдер) | бруд 0.85 · пил 0.3 · сколи 0.8 · потьоки 0.7 |

## Поведінка (однакова для всіх юнітів з баштою)

- Перед рухом корпус і башта одночасно плавно повертаються в напрямку руху, потім юніт їде
  клітинка за клітинкою.
- Атака з місця: корпус не рухається, башту на ціль повертає **лише той, хто атакує**;
  постріл з відкатом; башта лишається в цьому положенні.
- Ціль не повертає ні корпус, ні башту; якщо може — відповідає (шкода без відкату).
- Коли юніт стоїть — огляд ±45° навколо напрямку, куди башта востаннє цілилась.
- Юніт не темніє після ходу; спалаху й диму поки немає.
