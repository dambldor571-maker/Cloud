# Концепти обладнання (тест, не в основній моделі)

Скрипти будують поточну модель (`zmiy_build.py`) і додають поверх неї варіанти обладнання, потім
рендерять тестові зображення. Основну модель не змінюють.

| Файл | Що це |
|---|---|
| `sensors_abc.py`, `sensors_abc.jpg` | сенсорний блок, антени, Starlink: A — голова + Starlink на носі; B — без виступів; C — поворотна голова (Turret) + задній місток |
| `masts_m123.py`, `masts_m123.jpg` | надбудови: M1 — портал із профільної труби; M2 — відкидна телескопічна щогла; M3 — Т-пілон спереду |

```
blender -b --factory-startup --python concepts/sensors_abc.py -- <папка_для_зображень>
blender -b --factory-startup --python concepts/masts_m123.py -- <папка_для_зображень>
```

Рішення власника ще не ухвалене (робота повернулась до корпусу).
